👨‍🔧 ورشة محمد لصيانة السيارات

نعتمد منهجية عمل قائمة على التشخيص الشامل والفحص الدقيق للسيارة قبل تغيير أي قطعة غيار، لضمان معالجة العطل الحقيقي وتوفير التكاليف.

📢 ترقبوا الافتتاح

افتتاح الورشة المرتقب

نسعد بإعلامكم أننا بصدد تحضير افتتاح ورشتنا المجهزة بالكامل خلال شهر جانفي 2027. نقوم حالياً بتجهيز أحدث أجهزة الفحص.

خدماتنا
🛢️ Vidange + Filtres (تغيير الزيت والفلتر)
✅ تغيير زيت المحرك بأجود الأنواع ✅ تغيير فلتر الزيت، فلتر الهواء وفلتر الوقود ✅ فحص بصري شامل لمستوى السوائل
🛠️ Freinage (نظام الفرامل)
✅ فحص وتغيير صفائح الفرامل (Plaquettes) ✅ فحص وتغيير أقراص الفرامل (Disques) ✅ فحص مستوى وتغيير زيت الفرامل
🚗 Suspension (نظام التعليق)
✅ فحص واستبدال الأمصيورات (Amortisseurs) ✅ فحص رؤوس الأعمدة (Rotules) و Silentblocs
⚙️ Embrayage (علبة السرعة والفرامل)
✅ فحص طقم الفبرياج (Disque, Butée, Mécanisme) ✅ معالجة مشاكل ثقل تبديل السرعات
🔄 Kit Distribution (سلسلة التوزيع)
✅ تغيير كيت ديسانتري (Courroie de distribution + Galets) ✅ فحص مضخة الماء (Pompe à eau) وتغييرها عند الحاجة
💻 Scanner & Diagnostic (الفحص الإلكتروني)
✅ فحص شامل عبر أجهزة التشخيص الأصلية (ODIS, VCDS) ✅ قراءة أكواد الأعطال (DTC) ومسحها مع تقديم تقرير مفصل
🔧 Révision Moteur (العمرة الصغرى والكبرى)
✅ صيانة وإصلاح أعطال المحرك (Joint de culasse, Soupapes) ✅ ضبط دقيق لتوقيت المحرك (Calage moteur)
❄️ Climatisation (مكيف الهواء)
✅ فحص وشحن غاز المكيف وضغط الدائرة ✅ تغيير فلتر الكليمازيور وتطهير مجاري الهواء
⚡ Électricité Auto (الكهرباء العامة)
✅ فحص البطارية، الدينامو (Alternateur) والمارشور (Démarreur) ✅ كشف أعطال الأسلاك والفيوزات الإلكترونية
